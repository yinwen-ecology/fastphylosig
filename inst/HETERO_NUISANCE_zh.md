# Δ 异质性：处理共同 Q 不确定性的实验模式

**从 0.3.3.9021 起，全部 Δ 异质性检验移出推荐流程。** 推荐使用
`fast_hetero(method = "Delta", test = FALSE, overall = TRUE)` 描述局部及总体信号。
`overall_test = TRUE` 的原有整树信号检验仍可使用。本文件保存实验模式的研究说明，
显式 `test = TRUE` 的历史计算路径保留，不代表获得推荐资格。

以下技术说明基于 0.3.3.9018 及后续修订。接口默认 `test = FALSE`；只有显式
请求 Δ 检验时才采用 plugin 参考或选定的 nuisance 模式。

## 检验的含义

统计量仍是各冠群与总体 Δ 的对数比的均方根：

    H = sqrt(mean((log(Delta_local) - log(Delta_all))^2))

零假设是在给定树上，所有枝共享同一 Mk 生成矩阵 Q，根分布均匀。检验回答此 H 是否超出这一共同模型的预期。它不把 Δ 换成速率参数，也不等同于所有演化模型下的“信号相等”检验。

状态空间必须根据生物学预先指定，包含合法但本次末端未出现的状态。ER 支持 2–8 状态，速率域默认覆盖 [0,∞]；ARD 本版仅支持三状态及六个有向转移率。计算共同模型概率和模拟时保留完整状态空间；Δ 估计仍沿用原估计器，删除局部未观察状态。

## 用法

给定树 `tree` 和按物种命名的分类性状 `x`，事先确定生物学状态空间、切割、计算预算与检验规则：

```r
set.seed(20261016)
h <- fast_hetero(
  tree, x, method = "Delta", test = TRUE,
  min_tips = 50, max_tips = 200, nsim = 199,
  delta_control = list(
    model = "ER",
    state_space = c("A", "B", "C"),
    reference_test = "nuisance",
    nuisance_control = list(gamma = 0.001, max_boxes = 128, tolerance = 0.01)
  )
)
h$heterogeneity
plot(h, tree = tree)
```

这些数值是计算起点，尚不是新模式已校准的最优参数。MCMC 默认保持 10000 次、thin=10、burn=100；按原有 R-hat、ESS、比值 MCSE 检查 Δ 的数值可靠性。`nsim` 是提议参考库大小，不是每个 Q 重新模拟的次数。增加它可能改善权重与检出能力，不能保证搜索收敛，也不能弥补模型设定错误。

多性状可传入 `state_space = list(trait1 = c(...), trait2 = c(...))`，须覆盖所有性状名；共同向量则应用于每个性状。

三状态 ARD 默认覆盖六个速率的完整非负无界域。可直接将上例 `model` 改为 `"ARD"`。若有已有科学知识或独立资料给出的有限域，也可预先指定 `ard_bounds`：

```r
analyze_ard <- function(tree, x, ard_bounds) {
  fast_hetero(
    tree, x, method = "Delta", test = TRUE,
    min_tips = 50, max_tips = 200, nsim = 199,
    delta_control = list(
      model = "ARD", state_space = c("A", "B", "C"),
      reference_test = "nuisance",
      nuisance_control = list(rate_bounds = ard_bounds, max_boxes = 128)
    )
  )
}
```

`ard_bounds` 为 6×2 数值矩阵，第一列下界、第二列上界，单位为每单位枝长的转移率。按上例状态顺序，各行依次为 **B→A、C→A、A→B、C→B、A→C、B→C**。输出 `reference_model[[j]]$bounds` 保留行标签。不要围绕本次拟合 Q 事后设置上下界；那会失去这里的保证。

本版通过非负森林多项式的 resolvent 包络与对所有三状态 Q 一致的 Euler 误差界，覆盖所有无穷速率方向，包括多个速率按不同快慢尺度同时趋于无穷。无需给无限速率任意指定比例，也不截断到某个 Q_max。六维搜索仍可能因包络较宽而返回 1 或较大差距；这种结果不能证明没有异质性，也不代表已建立充分的检出能力。

`nuisance_control$boundary_power` 默认 24，允许 8–30。令 m=2^p，转移矩阵的近似误差由 `32/m` 向外包住，默认约 1.91×10^-6；这是转移概率包络的一部分，**不是 P 值误差容许值**。增加 p 增加平方次数，不能保证总体似然区间收窄，因为区间依赖与舍入误差也会累积。有限盒继续优先使用原均匀化内核。

`proposal_family = "auto"` 在 ER 下保留原五强度混合，在三状态 ARD 下加入六个事前固定的非对称成分：三种稀有状态 F81 排列及三种快速状态对，全部成分等权、逐份独立抽样。`"ER"` 可保留原提议；`"ARD"` 显式要求三状态 ARD。新增成分能改善部分稀有状态和快速状态对的权重，也会分走 ER 场景的抽样份额并增加密度计算成本，不能保证所有场景 ESS 都增加。不要根据当前性状或试验所得 P 值选择提议。

默认 plugin 分析的数值与随机流保持原样。ARD nuisance 是显式选择的实验模式，0.3.3.9014 开始实际搜索无界域，并新增提议成分，相对 .9013 改变了该模式的参考库及随机流。指定 `proposal_family = "ER"` 可保留原有限域实验的提议抽样方式。当前 .9015 的 correlation 改进不改变参考抽样，但可能改变报告的 P 上界。

`correlation = "auto"`（默认）在有限三状态 ARD 盒内启用共享参数 Taylor 模型：六个速率在不同枝长、转移元素、树消息及不同参考排列中使用同一组变量。最后针对 `(1-u)*A-u*B` 直接证明概率上下界，保留尾事件权重 A 和其余权重 B 的共同 Q。所有非线性与舍入误差进入严格余项，不是用一个点的梯度近似整个盒。与原包络相交，所以单个盒的界只会更紧或相同。

gamma>0 时，还用观测权重的同一模型保留置信集合与尾概率之间的相关性。若 H=归一化观测权重-gamma/K，则集合内 H>=0。对任意非负乘子 eta，`F+eta*H` 的有效上界也是集合内 F 的上界；`F-eta*H` 的有效下界也是其下界。有限乘子候选只用来寻找已验证的符号证书，不把近似最优乘子或点梯度当成证明。

为控制成本，auto 只处理非点有限盒，要求最大行半宽乘最长枝长不超过 0.15、乘全树总枝长不超过 0.5、最大退出率上界乘最长枝长不超过 256，且末端数乘压缩后排列数不超过 200000。这些阈值是计算成本保护，不是误差保证。`"taylor"` 可明确请求其他非点有限盒；极端刚性或浮点溢出会记录后退回旧包络。`"none"` 关闭新模型，便于事先设计的数值对照。无界盒始终保留原森林/Euler 包络；不能在多重无穷角点外推有限盒 Taylor 模型。自动筛选只在有效数值界之间选路，不改变统计零假设或参考库。

共享参数只保留至一阶，更高阶项用区间余项包住，仍会丢失部分相关性。提高每盒计算成本可能减少所需盒数，也可能只缩小差距而增加总耗时。尤其小预算的完整无界域搜索，可能完全没有适合的新有限盒，不能保证改善其 P 上界。

从 .9016 起，auto 还可对充分混合的宽盒或无界盒使用**共同森林平稳投影**。二边森林给出同一个 pi，各末端枝满足 `|P_ij(t)-pi_j|<=exp(-beta*t)`；beta 取共同重置和连续时间 Dobrushin 成对耦合的有效速率下界，不使用速率上限。后者也可覆盖没有共同重置列的快速单向循环。算法将整树似然包在同一 pi 上的多项式之间，再用 Bernstein 系数、置信集合对偶证书及最多 8 个单纯形子三角形给出概率界。计数合并的稀疏正均匀化复用已有区间内核；参考 Δ/MCMC 不重做。

该路径保留共享平稳部分，未保留全部瞬态相关性；每条末端枝的有限时间误差始终计入，没有假定性状已经独立或达到平稳。auto 仅在 Taylor 未使用时考虑它，要求 beta>0、最大末端误差不超过 0.05、至少两个观测末端、末端数乘压缩排列数不超过 2000000，且缺失掩码固定、速率盒非点。大树可单独用线性成本的似然夹逼/熵上界；只有观测末端数不超过 128 且末端数乘压缩排列数不超过 200000 时才增加 Bernstein 概率证书。`correlation="forest"` 可显式请求，误差成本保护上限放宽至 0.25；仍不绕过数学前提或规模保护。`"none"`、`"taylor"` 保持其原路径。

beta=0（包括完整 `[0,Inf]^6` 初始盒）、慢混合、多个闭类或超限区域继续保留旧有效界。gamma=0 时该模型仅收紧似然，保留旧概率计算，不在分母可能为零的区域强用比值证书。用当前数据选择速率下界以强行满足混合条件会改变科学问题，不允许据此缩小原参数域。

## 输出怎么读

| 字段 | 含义 |
| --- | --- |
| `P_heterogeneity`、`P_nuisance_upper` | 供检验决策使用的保守 P 上界 |
| `P_heterogeneity_kind` | `"nuisance_upper_bound"`，与原 plugin 概率区分 |
| `P_nuisance_lower` | 已确认在置信集合内的候选 Q 所给下界 |
| `nuisance_gap` | 加 gamma 和截断前的最大化上下界差距；可能大于报告 P 区间宽度 |
| `nuisance_converged` | 差距是否达到预先指定的 tolerance；不表示 Q 或 MCMC 收敛 |
| `nuisance_budget_limited` | 搜索预算耗尽，仍保留覆盖全部域的上界；该上界仍可保守决策 |
| `MCSE_P_heterogeneity` | NA；不能把重要性加权检验套进二项 MCSE 公式 |
| `nuisance_reference_attempted` | 实际尝试的参考份数；不因速率域无界而跳过模拟 |

这些上下界描述**当前固定参考库下的连续参数最大化**，不是误报率置信区间、真实尾概率置信区间或 Q 的置信区间。P 上界较大而下界较小时，不能从“上界不显著”推断没有异质性。`P_heterogeneity_lower` / `P_heterogeneity_upper` 仍属于旧 plugin 的未定义尾事件字段，本模式留为 NA。

`reference_model[[j]]` 保存参数域、根约定、ER 与 ARD 提议速率、每份参考的分类诊断、不可用参考的详细错误、搜索剩余盒子及各阶段用时。`search$boundary_covered` 表示包含所有边界，`boundary_Euler_error` 记录无界 ARD 的一致转移误差上界。`search$best_point_observed_weight_upper` / `search$best_point_ESS_lower` 是已找到候选点的权重诊断，不是整个参数域的最坏情况。`keep_null = TRUE` 另保存原始参考排列与尾事件标记，便于复核。

`search$correlation_evaluations` 记录实际启用共享模型的评估次数，`correlation_fallbacks` 单独记录其数值/刚性成本保护回退，不混入 Delta 拟合、MCMC 警告或实际计算失败。Q 搜索及新包络不消耗随机数，切换 correlation 不改变提议参考库或 Delta/MCMC 随机流。

`search$forest_evaluations`、`forest_fallbacks` 单独统计共同森林路径与数值保护回退，`forest_subcells` 累计其保留子三角形数。这些是数值包络诊断，不是优化器或 MCMC 警告。原始 C++ 盒审计另保留 beta、末端误差与收紧前概率上界。数学推导和独立核验见源码 `docs/signal-heterogeneity/ard-forest-shared-20261016/`。

从 .9017 起，auto 在前两条路径均未启用时考虑共同瞬态包络，`correlation="transient"` 可单独请求。三状态多闭类生成矩阵均可嵌入六个二边基准：一个瞬时态流向两个吸收态，或两状态闭类加一个吸收态。共同总速率 S 与分流比 rho 给出全部枝的精确基准瞬态；以 `u=exp(-S*t_min)` 紧化无界 S，保留 `exp(-S*t)=u^(t/t_min)` 的共同变量，不要求唯一平稳分布或正谱隙。

其余四条边没有忽略。若其最大行退出率上界为 delta，则每枝通过额外跳跃耦合保留 `1-exp(-delta*t)` 的误差。auto 要求最大误差不超过 0.15，显式 transient 放宽到 0.5；两者均要求末端数乘压缩排列数不超过 8192。最多 8 个内部矩形全部保留，复用原 C++ Taylor 模型、二幂 pruning 与尾概率证书。原盒似然与内部模型相交，但仅被观测置信集合排除的矩形仍参与无条件似然输出。

`search$transient_evaluations`、`transient_fallbacks` 和 `transient_subcells` 分别统计该路径实际启用、数值保护回退和内部矩形数。`witness_evaluations` 记录少量固定 ER 方向候选的检查次数；只有 C_gamma 成员资格已由原生点界确认，才可增加最大化下界。候选不改变提议参考库，不调用随机数，也不提供上界证明。none/taylor/forest 保留原路径。

完整 `[0,Inf]^6` 初始盒的余边也无界，不能直接使用这个小扰动包络。该域仍被原包络完整覆盖，低预算时上界可能保持 1；可验证候选提高下界不等于全域上界收紧。该功能覆盖所有多闭类基准及小余边邻域，不保证任意慢混合盒都获得紧界。推导和独立核验见源码 `docs/signal-heterogeneity/ard-transient-20261016/`。

.9018 进一步将四条慢余边放入四个共同坐标，与原 u/rho 一起保留一次额外跳跃中的乘积。令 J=I+B/delta，所有枝共用同一 J；在快基准 E 与有限时间衰减之间保留 EJ、JE、EJE，不假定它们可交换。仅两次及以上额外跳跃用 `Pr(Poisson(delta*t)>=2)` 包围，余项从一阶降为二阶。原误差/规模保护仍适用。节点处相同的后代状态组合只 pruning 一次，索引跨所有矩形和外层盒缓存，数值消息随每个新矩形重算，独立 MCMC 尾标记不合并。

auto/transient 另可使用完整域质量证书。三状态共同 Q 的返回概率下界与均匀根推出三个单态末端模式的总似然至少 `6^(-E)`，E 为树边数；加上模式互斥、总概率归一和 C_gamma 的观测似然约束，可直接限制加权尾概率，包含零边、多闭类和无界速率的概率极限。该界随树大小快速变弱，而且单状态参考在生产中进入上尾；不能把单态模式在非尾的数值探针收益外推为 Δ 必然同样改善。某些有限参考库的真实上确界就是 1，因此没有强制把上界压到 1 以下。

`search$transient_messages`、`transient_reuses` 统计实际计算与因节点模式重复而省去的内部消息；这是工作量，不是跨参数缓存旧数值。`mass_evaluations`、`mass_fallbacks` 单独记录全域质量证书及其保护回退。原生审计还保留单态总质量下界和收紧前上界。最终仍需加 gamma 并截断到 1，微小的原始上界改善可能不会降低最终 P；原始最大化 gap 与最终 P 宽度须区分。推导与核验见源码 `docs/signal-heterogeneity/ard-joint-20261016/`。

单状态参考的 Δ 仍是 NA，只在 H 的尾事件定义中扩展为 +∞；实际数值错误使检验不可用，不删除、不重抽。观测冠群不可估计时也不作拒绝。报告不可用率时须包含全部原始数据集，不能只报告成功子集的误报率。

## 数学依据与计算成本

只在拟合的 Q 下模拟，忽略了共同 Q 的估计不确定性。本模式对每个可能 Q 使用包括观测自身权重的校正重要性秩，其有限样本有效性来自 [Harrison (2012), Theorem 2](https://doi.org/10.1093/biomet/asr079)。

令 g 为不依赖本次性状、事前确定的正规化提议分布，构造

    C_gamma(y) = {Q : L_Q(y) >= gamma * g(y)}.

由 E_Q[g(Y)/L_Q(Y)]≤1 和 Markov 不等式，真 Q 被 C 排除的概率不超过 gamma；再按 [Berger–Boos (1994)](https://doi.org/10.1080/01621459.1994.10476836) 计算 `min(1, gamma + sup_{Q in C} p_Q)`。gamma=0 时覆盖全部预定域。实现对连续参数域求保守包络上界，预算用尽仍覆盖未搜索部分。有限网格最大值不能替代这一步。

所有 Q 共用一次提议参考库的 Δ 计算。树 core、Mk 模拟、ACE 工作区、熵与 MCMC 沿用已有 C++ 内核；新增 C++ 代码处理实际抽样核的概率、似然区间及权重。相同末端排列只计算一次目标似然，但保留每份参考独立 MCMC 的尾事件标记。Q 搜索不额外消耗随机数。`max_bank_bytes` 默认只约束整数排列矩阵为 64 MiB，不是进程总内存上限。

无界 ARD 的 resolvent 森林表示采用 [Chebotarev 与 Agaev (2002) 的矩阵森林定理](https://doi.org/10.1016/S0024-3795(02)00388-9)。本版另行推导 `||exp(tQ)-(I-tQ/m)^(-m)||_infinity <= 32/m`：三状态非零特征值位于 `|Im z| <= Re z/sqrt(3)`，结合标量误差及导数界、随机零特征投影和二阶矩阵插值，统一控制重根、可约链及任意大速率。森林分式在项目坐标中的非负 Bernstein 系数比包住完整无界盒；分母系数为零的项，其分子也为零。该一致常数及边界组合证明是本项目的推导，不是原文献已经发表的同一定理。完整推导与数值审计保存在源码 `docs/signal-heterogeneity/ard-unbounded-20261016/`。

共享模型沿用[仿射算术的一阶相关性表示](https://doi.org/10.1023/B:NUMA.0000049462.70970.B6)及严格 Taylor 余项框架；均匀化、pruning 和尾概率符号证书的具体组合推导与独立核验见源码 `docs/signal-heterogeneity/ard-correlation-20261016/`。矩阵幂每个盒只算一次，供所有枝长复用；ACE、Delta 与 MCMC 不重算。

只更换尾事件统计量；相同提议下仍执行相同全部估计与 MCMC。后者每份参考重新初始化
Polya 伪计数，不使用观测计数，实际 CDF 密度由原生核计算，不改变共同 Mk 零假设。
省略选项时默认结果和随机流不变；主动更换提议会改变新模式的参考库和随机流。

计数提议对快混合独立组成子模型给出多项式而非指数的组成失配界，但不能解决任意
慢混合、非可逆流量和多闭类的相关性覆盖。半混合有二阶矩最坏退化因子 2 的保护，
不保证逐例 ESS、P 或检出率改善。冠群间 SD 减少了总体偏离的混合解释，仍不是抽象
Delta 参数相等的分布无关检验。两项都没有据此获得新的独立功效校准或推荐资格。

冻结开发版 .9019：本功能仍为实验性。默认 plugin 是估计共同 Q 后的近似检验；
显式 nuisance 的推导控制只在下述固定模型和算法条件下成立。ER 支持 2--8 声明状态，
ARD 仅三状态，不能把有限域的结果解释为完整无界域保证。独立推导与高精度数值审计
不等于外部同行审阅，也不证明所有输入均无实现错误。预定的端到端验收只考察三状态、
32-tip 树和特定局部扰动；即使通过，也不外推到大型树、其他备择或全部状态数。

.9019 另保存 `search$raw_lower/raw_upper`、`final_width`、`stop_reason`、
`P_one_reason`、`gamma_clipped` 和 `bank_diagnostics`。`all_upper_tail` 表示库中没有非尾参考；
`certified_saturation` 表示已验证候选使最终 P 的下界也达到 1；`unresolved_envelope`
表示最终上界为 1 且原始最大化差距仍大；`gamma_ceiling` 表示差距目标已达到、原始上界小于 1，
但加 gamma 后被截断。`gamma_clipped` 单独记录截断，因此可与未决包络同时发生。
这些标签是诊断，不是新的显著性检验。所有剩余盒和原始 gap 仍保留。

闭合状态对与孤立状态的支持集检查仅选择确定性候选，仍须原生点界确认 C_gamma 成员资格。
只有最终下界已经为 1，才能提前停止搜索并报告 `[1,1]`；这节省无法拒绝的搜索，
不缩小全域、不改抽样库，也不改变默认 plugin 的结果与随机流。实际提议密度按
`clamp(cummax(CDF),0,1)` 的事件长度计算，兼容极端舍入阈值。

在指定共同 Mk 模型、均匀根、固定有根二叉树及严格正有限枝长、固定缺失掩码、与性状独立的切割/选择/参数域/提议下，推导给出**每性状、对原始输入和模拟无条件的误报上界**。辅助随机数按标准独立均匀随机流解释；未对伪随机数发生器作形式化证明。多性状、多种切割后挑最小 P 需另外处理多重比较。

该保证不涵盖模型失配、树/枝长估计不确定性、非随机缺失和只挑成功运行后的条件误报率。短 MCMC 的有限样本秩有效性也不等于 Δ 估计充分稳定。有限样本控制可能很保守，尤其六维 ARD：新模式尚无充分检出率证据，属于实验性实现，不能替换所有既有分析方案。
