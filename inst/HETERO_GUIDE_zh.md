# fast_hetero：支系信号、保守性格局与参考检验

从 0.3.4 起，推荐范围为：K 的 BM 参考检验、λ 的共同局部参数近似检验，
以及二元 D、多状态 Δ 的局部与总体描述。D 条件 ER 检验保持实验性；全部 Δ
异质性检验移出推荐流程。显式研究接口及默认值保留。
`test` 对所有方法一直默认 FALSE。

0.3.5 修正 ARD 祖先概率递推，因此 ARD Δ 的局部、总体估计、相关检验及后续
随机流可能与 0.3.4 不同；K、λ、D 和 ER Δ 的结果与随机流保持原有契约。
ACE 的 ER／ARD 速率标准误同时修正尺度，Δ 不使用这些标准误。
历史 ARD 校准不作为修正后估计器的有效性证据；推荐范围及实验性标注保持不变。

## 生物学问题与解释

局部信号值不同，可以描述为“在所分析尺度上，不同支系表现出不同程度的近缘
相似格局（系统发育保守性）”。这是有生物学意义的观察，不要求先得到异质性 P。
报告具体估计、差异大小、树的尺度、样本量、缺失和分类状态组成，通常比单独
给一个 P 更有信息。本文的“保守性”表示格局；稳定选择、生态位保守的过程及
低演化速率需要额外证据，不能仅由信号值推断。

可采用的表述：

- 描述：“A 支系的 K 高于 B，在本次切割尺度上表现出更强的系统发育信号。”
- 生物学解释：“该结果提示支系间系统发育保守性格局不同；仍可能受树形、
  样本量、测量误差或状态组成影响。”
- 参考证据：“冠群间 K 的离散超过给定树形的 BM 参考预期。”

一个类群的普通信号检验显著、另一个不显著，不能代替差异检验；参考 P 不显著
也不能证明两者相同。图上的整体信号 P、局部信号 P 和模型参考 P 分别回答问题。
同一指标内，较大的 K／λ／Δ 通常表示较强信号，较小的 D 表示较强聚集；D 可小于
0 或大于 1。它们都不是 PVR 的解释率，也不能跨指标比较数值大小。

## 零假设和适用范围

| 方法 | 局部离散描述 | 可选参考的零假设 | 推荐范围与限制 |
| --- | --- | --- | --- |
| K | SD(log K) | 给定冠群树形上的 BM；均值及正的扩散方差由不变性消去 | 核心 BM 参考；拒绝表示相对 BM 的异常离散，不能推广到所有同质演化过程 |
| λ | SD(λ) | 每个保留冠群从其自身根计量，共享局部 λ 的高斯协方差模型；均值和方差可各自不同 | 默认池化 REML 的近似参数 bootstrap；边界和小冠群仍有限制；不是整树共同 λ 检验 |
| D | SD(D) | 给定每个有效冠群状态计数及有限标准化模拟均值，共享速率的对称二状态 ER；根为 (1/2,1/2) | 描述推荐；新增异质性 P 实验性；单状态、稀少转移或退化标准化可不可用 |
| Δ | SD(log Δ)、局部／整体对数比及其 RMS | 推荐流程不进行 Δ 异质性检验 | 保留局部、总体、状态组成、拟合与 MCMC 诊断；原有普通信号检验仍可使用 |

K 的 Monte Carlo 秩检验在固定树、预定不重叠冠群和 BM 假设下有不变性依据，
不必代入共同均值或方差。其他同质过程仍可能拒绝 BM 参考。λ 和 D 的共同参数
来自数据，其 P 为近似参考概率；增加 nsim 只降低模拟误差，不消除参数估计偏差。
D 的参考不是 Fritz–Purvis 原论文已经建立的异质性检验，也不是二元 ARD 参考。

## λ 为什么要看切割尺度

整树共同 λ 不保证不同年龄冠群共享局部 λ。对超度量树，设根到冠群根距离为 s，
冠群内根到末端高度为 h；在 0 <= λ <= 1 时，冠群内部对比的协方差对应

    λ_local = λ * h / (h + (1 - λ) * s).

它是生成模型的参数关系，不是两个有限样本 ML 估计之间的等式。举例：整树 λ=0.6，
总高度为 4；h=1、s=3 的冠群对应约 0.273，h=3、s=1 的冠群对应约 0.529。
两者来自同一个整树模型，局部尺度参数仍不同。λ=0、λ=1 或 s=0 是特殊边界。
非超度量冠群一般不能用一个标量 λ 及方差重新表达整树限制后的协方差。
缺失剔除使保留物种的最近共同祖先移动时，实际比较尺度也会变化。

因此可描述不同尺度上的信号，但不能把当前共同局部 λ 检验直接称为整树过程
异质性检验。比较同一生物学层次时，尽量选择年龄、样本量相近的冠群并报告差异；
物种数量相近不保证年龄相近。无须把年龄差本身作为错误，也不要据此自动变换
观察 λ；上述公式不能直接修正带估计误差的观测值。这一尺度解释不要求变换估计值。

## 切割方式

| 目的 | 方式 | 检查内容 |
| --- | --- | --- |
| 比较事先提出的科、属或类群 | nodes 指定不重叠单系冠群 | 生物学身份、年龄、实际样本量和覆盖范围 |
| 大树初步扫描 | 按大小限制自动选择最大不重叠冠群 | coverage、uncovered_tips、冠群大小及年龄差 |
| 查看不同深度变化 | 指定嵌套节点，test=FALSE | 按尺度描述；重叠冠群不作为独立检验单元 |
| 尺度敏感性 | 事先确定少量范围并报告全部结果 | 不用最小 P 选尺度；多个方案不自动校正选择 |

自动切割用 C++ 遍历区间选择冠群，仅依赖树。树高度不平衡时可能只有一个
合适冠群，不保证全部物种被覆盖。不要把非单系残余拼起来，也不要为了达到
显著性更改切割。复用同一源树的 selection$nodes；替代树按物种集合重新对应。

可从 K／λ 的 min_tips=50、max_tips=200 起步；D 优先使用超过 50 个观察物种。
Δ 需检查每个冠群的状态支持和 MCMC；50–200 只是计算与设计起点。以上都不是
新异质性检验经全面验证的样本量阈值。max_tips 限制原始冠群大小，min_tips
检查每个性状剔除 NA 后的物种数。固定节点不等于固定信息量。

## 推荐工作流

```r
# tree、continuous_trait、binary_trait、categorical_trait 由你的数据提供。
# 主切割在查看性状结果前确定。
k <- fast_hetero(tree, continuous_trait, method = "K",
  min_tips = 50, max_tips = 200, test = TRUE, nsim = 999,
  overall_test = TRUE, overall_nsim = 999, progress = FALSE)
nodes <- k$selection$nodes

# λ：相同节点，但参考是共同局部 λ。
lambda <- fast_hetero(tree, continuous_trait, method = "lambda",
  nodes = nodes, min_tips = 50, test = TRUE, nsim = 999,
  lambda_reference = "REML", overall_test = TRUE, progress = FALSE)

# 二元 D：先描述聚集及相对整树的差异。
d <- fast_hetero(tree, binary_trait, method = "D", nodes = nodes,
  min_tips = 51, test = FALSE, d_nsim = 1000,
  overall = TRUE, overall_test = TRUE, progress = FALSE)

# 多状态 Δ：局部和总体描述；整体随机化 P 是原有信号检验。
delta <- fast_hetero(tree, categorical_trait, method = "Delta", nodes = nodes,
  min_tips = 50, test = FALSE, overall = TRUE, overall_test = TRUE,
  overall_nsim = 999, delta_control = list(model = "ER"), progress = FALSE)

# 指标、实际物种数、状态组成和诊断都应保留。
delta$clades
delta$overall
delta$heterogeneity  # SD(log Δ)、局部/整体 RMS；异质性 P 为 NA。
plot(delta, tree = tree, show.tip.label = FALSE, node_labels = TRUE)
```

模型根据生物学方案确定，ER 示例不是按 P 选择模型。Δ 的普通整体／局部信号检验
仍耗费置换及 MCMC 时间；只需描述时关闭 overall_test／clade_test。
plot() 不重新检验、不消耗随机数。可执行示例安装于 examples/heterogeneity-workflow.R。

D 的条件 ER 扩展只应在事先确定的探索方案中显式开启 test=TRUE；保留所有排除
冠群、不可用结果和标准化诊断。稀少转移旧场景仅 98/300 可用、2/98 拒绝，不能把
其余 202 个当成不拒绝证据。该测试限每冠群 1000 个观察物种，多项式计数概率
可能需要二次工作量。标准化 d_nsim 和异质性 nsim 控制不同的 Monte Carlo 误差。

## Δ 的保留范围和历史研究

全部 Δ 异质性 P 均不列入推荐，包括近似 plugin 和 nuisance 保守上界。
显式 test=TRUE 的实现保留，以复现历史研究；打印和树图标注实验性、非推荐。
[HETERO_NUISANCE_zh.md](HETERO_NUISANCE_zh.md) 记录研究控制，不作为推荐教程。
局部／总体 Δ、状态标签及计数、局部/整体差异、MCMC 和拟合诊断均保留。
单状态 Δ 不可定义，不能赋为零或解释为无保守性。优化器警告、成功数值恢复、
MCMC 警告及实际失败分别报告；良好收敛指标也不能消除状态信息不足。

推荐流程不要求数学上对所有进化过程成立才允许描述生态学格局。描述的强度应
匹配数据及比较尺度；若进一步使用“显著超过共同参考预期”，则同时写清参考模型。

## 来源与现有证据

- K：[Blomberg、Garland 与 Ives（2003）](https://doi.org/10.1111/j.0014-3820.2003.tb00285.x)。
- λ：[Pagel（1999）](https://doi.org/10.1038/44766)；上面的切割尺度关系为本包独立协方差推导。
- D：[Fritz 与 Purvis（2010）](https://pubmed.ncbi.nlm.nih.gov/20184650/)。
- Δ：[Borges 等（2019）](https://doi.org/10.1093/bioinformatics/bty800)。

局部扫描复用各方法的 C++ 内核。0.3.4 的 D 转移混合项与 lambda 最佳目标值
复用减少重复计算，K 内核保持不变。统计定义、参考模型、模拟次数及 RNG
顺序保持不变；数值实现通过验证不等于模型适用范围可以任意扩展。
