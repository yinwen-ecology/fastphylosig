# 性能证据的发布口径

0.3.4 复用 fast_k、fast_lambda、fast_d、fast_ace 和 fast_delta 的生产计算路径。当前发布准备没有再次运行大规模计时，也没有降低模拟次数或缩短 MCMC 来制造速度收益。结果/随机流契约与性能证据分别验证。

冻结前的受控 D/λ 优化比较使用相同 Windows 机器、R 4.6.1/GCC 14.3.0、1,024 tips、1 或 6 个性状、24–128 tips 自动冠群、完整或共享 NA 数据，`nsim=19, d_nsim=49`。三个轮次交替进程顺序，各保留首次与三次复用调用。计时不含输入生成、读入、prepare_tree、设置种子及后期比较中的 GC；编译/完整包检查未与计时并行。

| 工作负载与路径 | 基线中位秒 | 优化后中位秒 | 配对速度比中位数 |
|---|---:|---:|---:|
| D 异质性、6 性状、prepared | 0.450 | 0.340 | 1.324 |
| D 异质性、6 性状、raw | 0.430 | 0.330 | 1.333 |
| D 异质性、共享 NA、raw | 0.410 | 0.300 | 1.345 |
| λ 异质性、6 性状、prepared | 0.670 | 0.640 | 1.031 |
| λ 异质性、6 性状、raw | 0.660 | 0.630 | 1.048 |
| λ 异质性、共享 NA、raw | 0.620 | 0.590 | 1.051 |

这是版本标签仍为 0.3.3.9021 的冻结前优化实验；相关两个 C++ 文件与 0.3.4 逐字节一致。324 组基线/优化比较保留完整统计输出及 RNG 一致性。证据见 evidence/performance/；含全部控制场景、原始配对计时和逐次等价表。D 描述或短小场景不具有稳定通用收益，K 内核未改，不能据此宣称 K 加速。D 实验性检验的加速不使其成为推荐的确认性方法。

较早 0.3.3.9021 推荐参数端到端基准另列为历史规模参考：

| 工作流 | 5K tips 秒（3 次中位数） | 50K tips 秒（1 次） |
|---|---:|---:|
| K：999 次 BM 异质性参考和 999 次普通整体随机化 | 0.78 | 10.50 |
| λ：999 次共同局部参数参考与整体 LRT | 11.88 | 119.83 |
| D 描述：1,000 次标准化及普通整体信号检验 | 1.54 | 18.78 |
| 三状态 Δ ER 描述、含整体估计 | 0.84 | 10.01 |
| 三状态 Δ ARD 描述、含整体估计 | 2.12 | 23.67 |

历史规模基准使用一个性状、固定输入、一个逻辑 CPU；Δ 两链各 10,000 步、burn=100、thin=10。Δ 不含异质性或整体置换，D 不含异质性参考。5K Δ ARD、50K Δ ER/ARD 各有 3 个局部和 1 个整体 MCMC 警告，全部保留。50K 仅单次观察；此表不是本次 0.3.4 新计时，也不是默认设置下所有分析的速度保证。原始 20 次调用与方案说明置于 evidence/performance/historical-scale/。

发布说明采用“减少重复计算，收益依赖工作负载”的表述，不把小模拟数微基准当作 999 次参考的计时，也不把算法运行速度解释成统计检验已经充分校准。
