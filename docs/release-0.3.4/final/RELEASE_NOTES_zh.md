# fastphylosig 0.3.4

0.3.4 提供 `fast_hetero()` 支系尺度分析：按预定节点或大小限制选择单系冠群，计算局部与总体系统发育信号，汇总覆盖率、实际样本量、缺失、状态组成和诊断，并在树图中显示结果。图中区分整体普通信号检验与异质性参考检验。

局部信号差异可用于描述所分析尺度上的系统发育保守性格局。信号值不是 PVR 解释率，差异本身也不识别稳定选择、生态位保守过程或演化速率变化。

| 方法 | 本版推荐范围 | 异质性参考的定位 |
|---|---|---|
| K | 局部与总体描述、普通信号检验、BM 参考离散度检验 | 固定树和预定不重叠冠群上的 BM 参考；不推广到所有同质演化过程 |
| λ | 局部与总体描述、普通信号检验 | 共同局部冠群 λ 的近似高斯参考；默认池化 REML，整树共同 λ 不保证局部 λ 相同 |
| D | 二元性状局部与总体描述、原有随机/Brownian 信号检验 | 给定冠群状态计数的共同对称 ER 异质性扩展仍为实验性 |
| Δ | 多状态性状局部与总体描述、状态组成、局部/总体差异、拟合和 MCMC 诊断，以及原有普通信号检验 | 全部 Δ 异质性检验不在推荐流程中；显式研究接口保留并标注实验性 |

`fast_hetero()` 的 `test` 默认保持 `FALSE`。普通局部/整体信号 P 值与异质性参考 P 值分别报告。单状态 Δ 不赋零；成功数值恢复、优化器重试、剩余优化器警告、MCMC 警告及实际失败保持可区分。

本版整理和修复包括：

- 显式 `nodes` 覆盖自动切割大小限制；`min_tips` 仍检查每个性状实际观测数，节点与内存保护保留。
- D 复用子节点转移混合项，λ 复用 Brent 最佳点对应的目标值，减少重复计算。统计定义、参考模型和模拟次数不因加速而改变。
- ARD 恢复回归在同一参数向量上比较独立似然，保留原数值容差，并要求改善同次运行的未完成拟合。
- 删除两个未使用的私有编码辅助函数，更新帮助页、可执行短示例与指南，修正手册长代码换行。

14 个公开函数的参数和默认值相对上一冻结候选版保持一致。固定输入下的 12 组完整结果、诊断和随机流回归逐项一致；性能收益依赖工作负载，不作通用速度倍数承诺。

Windows 独立检查完成全新编译、完整测试、示例和 PDF/HTML 手册检查：0 ERROR、0 WARNING、1 NOTE（incoming 的 `New submission`），13,679 项断言通过，1 项历史跨安装测试跳过。K 四模式开发桥接测试另行通过 27 组比较。Linux 检验通过由维护者确认；本地未另行复核其日志。其他平台未列为本轮已验证配置。

源码安装需要 C++17 工具链，OpenMP 为可选项。源码包名为 `fastphylosig_0.3.4.tar.gz`，安装命令为：

```r
install.packages("fastphylosig_0.3.4.tar.gz", repos = NULL, type = "source")
```
