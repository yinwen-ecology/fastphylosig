# RC1 推荐工作流的端到端基准

方案在计时前固定，见PLAN_zh.md。硬件为AMD Ryzen 7 5800H，Windows 11，
R 4.6.1/Rtools45。每例一个R进程，绑定一个逻辑CPU，ACE线程固定为1；没有与
编译或测试并行。每种树大小使用同一保存的随机二叉树和互异U(.25,1.75)正枝长。
一个性状、完整数据；连续输入按整树λ=.6协方差生成，分类输入按对称ER生成。
生成仅用于固定性能输入，不用于本轮科学校准，输入生成不计入函数耗时。

| 工作流 | 5K tips，秒（3次中位数） | 50K tips，秒（1次） | 50K进程峰值工作集 MiB |
| --- | ---: | ---: | ---: |
| K，999次BM异质性参考及999次普通整体随机化 | 0.78 | 10.50 | 310.5 |
| λ，999次共同局部参数参考及整体普通LRT | 11.88 | 119.83 | 324.0 |
| D描述，1000次标准化及普通整体信号检验 | 1.54 | 18.78 | 368.2 |
| 三状态Δ ER描述，含整体估计 | 0.84 | 10.01 | 332.8 |
| 三状态Δ ARD描述，含整体估计 | 2.12 | 23.67 | 335.5 |

Δ均为默认LSE、两链各10000步、thin=10、burn=100；没有异质性参考或整体置换。
D异质性参考关闭。K/λ主切割为50–200 tips，D为51–200；5K有39个冠群（D为38），
50K有380个冠群（D为378）。K/λ/Δ覆盖率分别96.92%与93.702%；D分别95.92%与
93.502%。没有为了提高覆盖率拼接残余物种。所有匹配、树编译、切割、估计及所列
检验均计时；绘图、输入生成、包安装和编译不计时。

每例先进行一次不计时热身：K/λ使用2次参考，D标准化19次，Δ链长不变。
5K每例测量3次，50K每例1次，共20次完整参数分析。50K数字是单次观察，不能
当作稳定时间估计或用来给出精密速度比；没有与其他包做等任务比较。

## 结果与诊断

- 20次计时均返回结果，整体状态均为ok；K/λ每次999个参考全部成功。
- 5K每例的第2、3次与第1次，完整非计时结果、警告、最终RNG及后续均匀/正态
  数均严格一致，共10个重复合同。没有重新抽取输入、删除慢运行或换种子。
- 5K Δ ARD、50K Δ ER及ARD，各有3个局部冠群和1个整体估计触发MCMC警告，
  每次返回2条汇总warning。所有估计及诊断保留，没有把警告当作实际计算失败，
  也不把可用值当作已经可靠收敛的证明。本输入未触发优化器警告或数值恢复。
- 这组工作负载中λ最耗时；D/Δ描述的时间不包含其额外异质性实验检验。Δ
  若开启999次整体置换需另付ACE/MCMC成本，这张表不能代表那一选项的时间。

峰值内存使用ps包读取Windows进程peak_wset（与PeakWorkingSet64对应），是
整个R进程的峰值，包含包加载、输入、热身、已保存结果和R分配器，并非单个函数
新增分配。独立PowerShell采样工作集每250ms记录一次，见process-monitor.csv。
基准工具ps不加入fastphylosig依赖。

## 复现材料

- 原始输入：benchmark/input-5000.rds、input-50000.rds及各输入种子。
- 原始20次计时与全部状态：benchmark/all-timings.csv。
- 汇总：benchmark/summary.csv；硬件与CPU绑定：hardware.json、process-monitor.csv。
- 完整估计、诊断、警告和RNG：每例*-results.rds；热身对象另存。
- 每进程sessionInfo、stdout、stderr均保留。

本轮只做验收，不更改任何计算路径，不将描述性分析的速度当作正式异质性推断
已经得到充分验证的证据。
