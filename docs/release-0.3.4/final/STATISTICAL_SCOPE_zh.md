# 0.3.4 冻结的统计适用范围

此范围与包内帮助、打印和树图标注一致。`fast_hetero()` 先按树选择冠群，复用现有 fast_* 生产计算路径，再汇总局部和总体结果；默认不进行异质性检验。

| 方法 | 可报告的格局 | 可选参考与限制 |
|---|---|---|
| K | 局部/总体 K、SD(log K)、普通信号检验 | 固定树、预定不重叠冠群上的 BM 离散参考。均值和正扩散尺度由不变性消去；拒绝仅说明偏离该 BM 参考 |
| λ | 局部/总体 λ、SD(λ)、普通信号检验 | 每个保留冠群从自身根计量的共同局部 λ 高斯模型；均值、方差可各自不同。池化 REML 为默认近似 bootstrap，边界和小冠群仍有限制 |
| D | 二元 D、SD(D)、状态计数/频率及原有随机/Brownian P | 新增异质性 P 为实验性：给定每冠群状态计数及有限标准化模拟均值的共同速率对称 ER，根为 (1/2,1/2)。它不是原 Fritz–Purvis D 信号检验，也不是二元 ARD 参考 |
| Δ | 多状态局部/总体 Δ、SD(log Δ)、局部/总体对数比及 RMS、状态组成、拟合/MCMC 诊断与原有普通信号检验 | 推荐 `test=FALSE`。全部 Δ 异质性 P 不在推荐范围；显式 plugin/nuisance 研究调用保留，但不能作为发布推荐的确认性结论 |

局部数值差异可以描述为“在本次分析尺度上，支系间系统发育保守性格局不同”，不要求先得到异质性 P。须同时报告具体数值、差异大小、尺度、实际观测数、缺失与状态组成。一个普通信号 P 显著而另一个不显著，不能代替差异检验；未拒绝参考也不证明同质。信号格局自身不识别稳定选择、低演化速率或生态位保守机制。

主切割应在查看性状结果前确定。优先使用有生物学含义、年龄和样本量可比的不重叠单系冠群；大树探索可用最大不重叠冠群自动扫描。不能把非单系残余拼接起来，不用最小 P 选择尺度。嵌套节点仅作 `test=FALSE` 的尺度描述；多个性状或切割方案的选择不自动获得多重比较校正。

K/λ 可从 `min_tips=50, max_tips=200` 开始，异质性参考可用 `nsim=999`。D 优先超过 50 个实际观测物种，描述分析可用 `min_tips=51, d_nsim=1000, test=FALSE`。Δ 可从 50–200 物种冠群开始，按预先确定的生物学模型选择 ER/ARD，并检查每冠群状态支持。以上是设计和计算起点，不是适用于所有数据的已验证充分样本量。

λ 的冠群大小相似不保证年龄相似。对超度量树，整树参数在 [0,1] 时，内部对比对应的局部模型参数为 `lambda*h/(h+(1-lambda)*s)`，h 为冠群高度，s 为祖先深度。它不是观测 ML 估计间的等式；非超度量冠群一般不存在相同的单标量转换。缺失剔除后的根收缩也会改变实际尺度。当前检验应称共同局部 λ 参考，不称整树共同 λ 过程的精确异质性检验。

Δ 保持默认两链各 10,000 步、`burn=100, thin=10`，不为性能自动缩短链。按 ESS、split/rank-normalized R-hat 和估计 MCSE 判断是否需要延长。单状态或拟合失败保持不可用，不赋零、不补抽样替代；不得删除警告或失败后仅以成功子集宣称通过。增加 `nsim` 只减少参考模拟误差，不能修复拟合偏差或模型不适用。

`overall_test`/`clade_test` 是普通信号检验，与 `test` 的异质性参考独立。Δ 整体置换会重复 ACE/MCMC，应明确其额外成本。`plot()` 展示已有结果，不重新检验或推进随机数。完整工作流见 [安装指南](inst/HETERO_GUIDE_zh.md)；[历史 nuisance 文档](inst/HETERO_NUISANCE_zh.md) 是实验性研究记录。
