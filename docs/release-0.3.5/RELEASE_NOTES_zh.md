# fastphylosig 0.3.5

发布日期：2026-10-21。计算实现冻结自已审核的 0.3.4.9003；
正式发布准备仅更新版本元数据与说明，
不改变数值算法、公开接口或默认参数。

## 修复对现有分析的影响

| 修复 | 影响范围 | 重算建议 |
| --- | --- | --- |
| ARD 全树祖先概率递推方向 | `fast_ace(model = "ARD", marginal = FALSE)` 的祖先概率，以及使用它的 ARD Δ、置换、局部／总体汇总和实验性参考检验 | 使用已发布 0.3.4 得到这些输出的分析，应重算受影响部分。保留原始输入、参数和种子，并记录修正后的版本。 |
| 离散 ACE 速率标准误尺度 | ER、ARD 的速率 `se` 字段 | 使用过这些 SE 的不确定性汇总应重算。有限 SE 增为原值的 sqrt(2) 倍；此项修复不改变速率点估计和似然。 |

在行生成矩阵约定下，`P[i,j]` 表示父状态 i 转为子状态 j 的概率，
递推分母应为 `P %*% L_child`。合法的不可达 ARD 父状态在后验和子节点贡献
均为零时发送零消息；后验为正但贡献为零时仍报告失败。

ACE 的目标函数是负二倍对数似然，观测信息为该目标 Hessian 的一半，
因此 SE 使用 `sqrt(2 * diag(solve(Hessian)))`。边界或不可识别拟合仍可能
产生不可用 SE，原有诊断保留。Δ 不估计或使用这些速率标准误。

ARD 概率修复可能改变熵、MCMC 接受路径和端点扰动，因此同一种子也可能得到
不同的 ARD Δ 和后续随机数状态。这是数学修复的预期影响。递推修复不改变
拟合速率所用的似然目标；K、λ、D 和 ER Δ 保留结果与随机流契约。
ER 的 ACE 标准误仍受上述尺度修复影响。

## 性能与缓存维护

保留已审核的精确指数缓存，修复几何重新配置时旧状态残留及哈希节点内存计数。
正常 R 路径只在不可变工作区构造时配置一次，未触发旧的重新配置问题。
分配或计算失败不会发布不完整缓存列。

小矩阵运算直接复用既有 Armadillo GEMV 分派，并减少缓冲区准备和复制。
未引入近似指数、替换 BLAS、减少拟合／MCMC 预算或修改 MCMC 内核。
相对上一开发快照 0.3.4.9002，独立完整流程计时中，512 tips 的局部加总体
ARD Δ 扫描耗时下降 4.88%，256 tips 稀有状态梳状树案例下降 3.43%。
这是本机 Windows 的增量测量，不是相对已发布 0.3.4 的加速结论。

## 保留的统计范围

- K：局部／总体估计，以及预先确定的不重叠冠群上的 BM 参考离散检验。
- λ：局部／总体估计，以及默认池化 REML 的共同局部冠群参数近似高斯参考；保留冠群尺度解释。
- D：推荐二元性状的局部／总体描述；保留状态计数的共同对称 ER 异质性检验仍为实验性。
- Δ：推荐多状态性状的局部／总体描述、状态组成、拟合与 MCMC 诊断；全部异质性检验仍为实验性，不进入推荐流程。

普通信号检验与异质性参考检验继续分别报告。全部失败、数值恢复、优化器和
MCMC 警告保留。历史 ARD 校准不能作为修正后估计器的有效性证据。
局部信号差异可以描述所分析尺度上的系统发育保守性格局，演化机制和速率变化
需要另行研究。公开函数名、参数、默认值与结果类均保持不变。
