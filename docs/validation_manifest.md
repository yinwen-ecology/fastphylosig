## Source snapshot algorithm

The authoritative tarball is extracted and every regular file is hashed with
SHA-256. For each of the 88 files, one record is formed as:

```text
forward/slash/relative/path<TAB>lowercase-file-sha256<LF>
```

Records are sorted by relative path, concatenated as UTF-8 without BOM, and
the resulting bytes are hashed with SHA-256. The result is the authoritative
source snapshot SHA-256 above. This avoids tar metadata and manifest
self-reference.

## Required smoke entry points

The clean-install smoke loaded the authoritative tarball in a new R library
and a fresh R session, then called `fast_k()`, `fast_lambda()`, `fast_d()`,
`fast_delta()`, `fast_ace()`, `check_tree()`, and `fast_signal()`.
