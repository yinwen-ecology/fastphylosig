# Post-0.2.0 Plan

This document records possible work after the fastphylosig 0.2.0 release. It is a planning record only; it does not authorize implementation or reopen frozen release evidence.

## 0.2.1

The 0.2.1 scope is limited to maintenance and release follow-up:

- confirmed bug fixes;
- documentation corrections;
- installation and release issues; and
- responses to CRAN feedback.

Any newly discovered non-blocking issue may be recorded in this file with its evidence, impact, and proposed disposition. Recording an issue does not start a new audit or implementation automatically.

Rejected K and D candidates remain closed. This plan does not authorize their reactivation or any new estimator, numerical algorithm, or performance candidate.

## 0.3.0

The 0.3.0 scope is limited to separately authorized future work:

- future architectural features;
- cross-platform qualification work;
- major performance experiments; and
- new public API work.

Each item requires an explicit scope, evidence, and acceptance criteria before development begins. Rejected K and D candidates are not reopened automatically and remain outside the release plan unless a separate decision explicitly changes their status.
