Development regression fixtures only; not independent calibration inputs.
Five cases from the fixed 0.3.3.9009 audit: four unfinished observed crowns and
one full-tree simulated ARD fit requiring the bounded fallback. Each contains
original workspace, states, full original optimizer return, recovered fit and
independent expm/base-R-pruning deviance. Generated by
docs/signal-heterogeneity/ard-local-recovery-20261015/verify-recovery.R.
The 46-case development capture and alternative optimizers are retained there.

The saved independent deviance is evaluated at the saved recovered `fit$par`.
It is not a platform-independent optimum that a new optimizer run must match.
The regression test therefore checks saved rates against that saved reference,
and newly fitted rates against a fresh independent expm/base-R-pruning oracle,
at the original 1e-8 tolerance. It separately requires convergence, improvement
over the current unfinished baseline, valid probabilities and unchanged RNG.
